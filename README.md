# Joe Farewell — GitHub Pages

## Publish
1. Create a new GitHub repository, e.g. `joe-farewell`.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose **main** and **/(root)**, then Save.
6. GitHub will give you a public URL such as:
   `https://Lithiumoxide.github.io/joe-the-legend/`

Once you have the final URL, use it to generate the QR code.
